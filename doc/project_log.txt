  Changes Made to Get the Async FIFO HDL Working

    1. Use of Unregistered Read Pointer for Memory Access
      - The read pointer was previously registered before being used to index the RAM.
      - Because the RAM has a one-clock-cycle read latency, the output data becomes valid 
        one cycle after the read pointer updates.
      - This delay caused misalignment between m_tdata and m_tvalid pulses, 
        resulting in incoherent output behavior.
      - The issue was resolved by using the unregistered read pointer directly for RAM addressing, 
        ensuring proper synchronization between data and valid signals.

    2. Use of logic Instead of reg and wire
      - All signals and registers were redefined using the logic type for better SystemVerilog 
        compatibility and to simplify synthesis and simulation.

    3. One-Cycle Delay on s_tready
